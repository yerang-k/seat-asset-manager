# 전주솔내고등학교 교직원 좌석 중심 PC·모니터 관리 시스템

학교 내 교직원용 컴퓨터와 모니터를 **사람(교사)이 아닌 '교무실 좌석(자리)'을 중심으로 관리**하는 Google Apps Script + Google Sheets 웹 애플리케이션입니다.

2026학년도 전주솔내고등학교 실제 교직원 좌석배치도 구조(교장실, 교무센터, 1·2·3학년 교무실, 학생안전부, 통합지원반, 교육정보부, 상담·보건·급식실, 행정실, 특별실 등 총 98석)를 디지털 인터랙티브 뷰로 정밀 복원하였습니다.

---

## 🎯 핵심 해결 과제

1. **연간 인사이동 및 자리 변경 시 재조사 부담 제거**:
   - 기존: 교사 개인 이름으로 컴퓨터/모니터 이력이 관리되어, 매년 자리가 바뀌면 모든 사양을 다시 입력해야 함.
   - 변경: **좌석(자리)에 PC와 모니터가 고정 귀속**되므로, 새 학년도에는 좌석의 **'선생님 성명'만 갱신**하면 끝납니다.

2. **Gemini Vision AI 라벨 자동 인식 (초간편 현황 조사)**:
   - 스마트폰으로 PC 본체나 모니터 뒤에 부착된 K-에듀파인 물품관리 스티커 또는 제조사 스펙 명판을 찰칵 찍으면,
   - **Gemini AI**가 제조사, 모델명, 취득일자(제조연월), 물품관리번호, 시리얼번호를 자동으로 판독해 입력란을 채워줍니다.

3. **구글 시트 5만 자 용량 한도 해결 (사진 구글 드라이브 자동 연동)**:
   - 기기 사진은 스프레드시트 셀에 base64로 직접 넣지 않고, 구글 드라이브 전용 폴더(`[전주솔내고] 기기관리_사진`)에 자동 업로드한 뒤 URL 링크만 시트에 보관하여 스프레드시트 용량 제한 및 깨짐 문제를 근본적으로 해결했습니다.

## 🚀 배포 방법 (Google Apps Script)

### 1단계: 구글 스프레드시트 생성
1. [Google 스프레드시트](https://sheets.google.com)에서 새 문서를 만듭니다.
2. 문서 제목을 `2026 전주솔내고 교직원 PC·모니터 관리대장`으로 지정합니다.

### 2단계: Apps Script 편집기 열기 및 코드 복사
1. 스프레드시트 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
2. 기본 `Code.gs` 내용을 지우고, 이 저장소의 `Code.gs` 내용을 붙여넣습니다.
3. 좌측 **[+] 파일 추가 > [HTML]**을 누르고 파일명을 `index`로 생성한 뒤, `index.html` 내용을 붙여넣습니다.
4. 상단 저장 아이콘(Ctrl + S)을 눌러 저장합니다.

### 3단계: 초기 데이터 자동 생성 (원클릭 셋업)
1. Apps Script 상단 함수 선택 드롭다운에서 **`초기데이터생성`**을 선택하고 **[실행]**을 누릅니다.
2. 최초 실행 시 구글 계정 권한 승인 창이 뜨면 승인합니다.
3. 실행이 완료되면 스프레드시트에 **`[좌석]` (98개 좌석), `[기기]`, `[교무실]`** 시트 3종이 서식과 함께 자동으로 생성됩니다.

### 4단계: Gemini API 키 설정
1. Apps Script 좌측 메뉴의 **톱니바퀴 아이콘 [프로젝트 설정]**을 클릭합니다.
2. 하단 **[스크립트 속성] > [스크립트 속성 추가]**를 클릭합니다.
3. 속성 이름: `GEMINI_API_KEY`
4. 속성 값: 발급받은 Gemini API 키 입력 후 저장합니다.

### 5단계: 웹앱 배포
1. 우측 상단 파란색 **[배포] > [새 배포]** 클릭.
2. 유형 선택(톱니바퀴): **[웹 앱]** 선택.
3. 설정:
   - 설명: `v1.0 전주솔내고 좌석 기기관리`
   - 다음 사용자로 실행: **[나]**
   - 액세스 권한: **[모든 사용자]** (또는 학교 도메인 사용자)
4. **[배포]**를 누르고 생성된 웹앱 URL을 복사하여 교직원 메신저나 QR 코드로 공유합니다!

## 💻 로컬 브라우저에서 바로 테스트하기

Apps Script 배포 전에도 본 컴퓨터에서 즉시 실행하고 조작해 볼 수 있습니다:

1. `index.html` 파일을 더블 클릭하여 크롬(Chrome)이나 엣지(Edge) 브라우저에서 엽니다.
2. 로컬 모드에서는 브라우저의 `localStorage`를 사용하여 데이터 추가, 수정, 삭제가 즉시 동작합니다.
3. 우측 상단 **[⚙️ 설정]**에서 본인의 Gemini API 키를 넣으면 로컬에서도 실제 AI 라벨 판독 기능을 테스트할 수 있습니다.
